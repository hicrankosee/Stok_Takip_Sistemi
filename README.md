Stok Takip Sistemi

​.NET Framework ve C# kullanılarak geliştirilmiş masaüstü tabanlı bir Stok Takip Sistemi uygulamasıdır. Bu proje, depo veya ürün yönetiminde temel işlemlerin hızlı ve düzenli bir şekilde yapılmasını sağlar.

​Özellikler:
​Ürün Yönetimi: 10 adet TextBox alanı ile ürün detayları ayrıntılı bir şekilde girilebilir.

​CRUD İşlemleri: Sisteme yeni ürün ekleme, mevcut ürünleri güncelleme ve ürün silme işlemleri eksiksiz olarak yapılabilmektedir.

​Tasarım: Windows Forms kullanılmıştır. 
​

​Dil: C#

​Framework: .NET Framework

​Arayüz Teknolojisi: Windows Forms

​Nasıl Kullanılır?:
​Projeyi bilgisayarınıza klonlayın veya ZIP olarak indirin.
​Dosyayı Visual Studio üzerinde açın.
​Projeyi derleyip çalıştırarak form ekranı üzerinden stok işlemlerini gerçekleştirebilirsiniz.
